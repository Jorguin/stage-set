# 🎸 Stage Set

**Stage Set** es una aplicación web diseñada para músicos y bandas que buscan organizar sus canciones y repertorios de forma sencilla para ensayos y presentaciones en vivo.

La aplicación centraliza canciones, cifrados y setlists en un solo lugar, incorporando herramientas para preparar repertorios y utilizarlos durante una presentación.

## ✨ Funcionalidades

* 🎵 Gestión de canciones, letras y cifrados.
* 📋 Creación, edición y organización de setlists.
* 🎤 Vista de escenario para consultar el repertorio durante una presentación.
* 🎯 Modo de práctica para preparar canciones y repertorios.
* 📊 Seguimiento del progreso de práctica.
* 🔗 Compartición de setlists mediante enlaces.
* 👥 Gestión de bandas y colaboradores.
* 🔐 Autenticación de usuarios.
* 📱 Experiencia como Progressive Web App (PWA).

## 🎯 Objetivo del proyecto

Stage Set nació como un proyecto personal enfocado en resolver una necesidad concreta dentro del entorno musical: disponer de una herramienta centralizada para organizar repertorios, preparar presentaciones y facilitar el acceso a las canciones durante una actuación.

El proyecto continúa en desarrollo y sus funcionalidades pueden evolucionar con el tiempo.

## 🤖 Desarrollo asistido por IA

El proyecto fue desarrollado utilizando herramientas de inteligencia artificial como asistencia durante la implementación.

La IA se utilizó como herramienta de apoyo para convertir la idea y los requerimientos del proyecto en una aplicación funcional, mientras que el desarrollo involucró la definición de funcionalidades, configuración de servicios, pruebas, evaluación de resultados y toma de decisiones sobre el producto.
